结构

24×24 viewBox，2.2px 圆头轮廓；主体尽量控制在 3–21px 安全区。

双色预算

蓝色构成主体，绿色只占一个局部焦点；不靠绿色单独表达业务状态。

识别优先

放大稿用于看结构，24px 才是淘汰标准；小尺寸发糊的图案不进入实现。

本批次是可编辑 SVG 概念源，不代表已经进入生产 assets。视觉基线见 图标与配色确认稿。
